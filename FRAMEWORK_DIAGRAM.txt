                              APPLICATION WORKFLOW

Step 1: Data Preparation
┌──────────────────────────────────────────────────────────────────────────┐
│ $ python src/merge_vt_features.py                                        │
│                                                                           │
│ Inputs:  • data/processed/phishing_graph_features.csv                   │
│          • VirusTotal API                                                │
│ Output:  • data/processed/phishing_graph_features_vt.csv                │
└──────────────────────────────────────────────────────────────────────────┘

Step 2: Model Training
┌──────────────────────────────────────────────────────────────────────────┐
│ $ export ALL_FEATURES=data/processed/phishing_graph_features_vt.csv     │
│ $ python src/train_model.py                                              │
│                                                                           │
│ Process: • Load & validate data                                          │
│          • Remove duplicates (221,847 → 159,603 unique URLs)           │
│          • Detect data leakage (drop suspicious columns)                 │
│          • Train/test split (80/20 stratified)                           │
│          • Train Random Forest                                           │
│          • Evaluate performance                                          │
│                                                                           │
│ Outputs: • models/phishing_rf_model.pkl (trained model)                 │
│          • models/training_metrics.json (performance data)               │
└──────────────────────────────────────────────────────────────────────────┘

Step 3: Prediction & Explanation
┌──────────────────────────────────────────────────────────────────────────┐
│ $ python src/risk.py                                                     │
│                                                                           │
│ Process: • Load trained model                                            │
│          • Load test/new URLs                                            │
│          • Generate predictions                                          │
│          • Calculate SHAP values                                         │
│          • Create visualizations                                         │
│                                                                           │
│ Outputs: • SHAP bar plots (PNG files)                                   │
│          • SHAP force plots (Interactive HTML)                           │
│          • Risk scores and classifications                               │
└──────────────────────────────────────────────────────────────────────────┘
